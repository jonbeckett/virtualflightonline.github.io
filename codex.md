# Codex

The **Codex** is the reference side of Virtual Flight Online: a place for guides, operating notes, setup walkthroughs, and practical documentation.

## What belongs in the Codex

The original VFO navigation links to a separate Codex site. As content is migrated here, the Codex is expected to grow into a structured knowledge base covering topics such as:

- simulator setup and optimisation
- aircraft-specific tips and workflows
- VFO operations and event procedures
- Transmitter configuration and troubleshooting
- live tracking, mapping, and data-feed integration

## Draft categories

| Category | Planned focus |
| --- | --- |
| Getting Started | First steps for new VFO members |
| Simulator Setup | Core setup guidance for MSFS and X-Plane |
| Operations | Shared procedures, events, and group-flying notes |
| Tools & Integrations | Radar, Little Navmap, feeds, and related utilities |
| Troubleshooting | Common issues and proven fixes |

## Available draft content

The strongest draft material available today sits under [Operations](operations/), especially the Transmitter pages.

## Why this matters

A good Codex gives the community a home for practical knowledge. It means fewer repeated questions, faster onboarding for new members, and a better place to capture the working habits that make shared virtual flying smoother.
