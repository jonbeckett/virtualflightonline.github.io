# Scenery

Scenery add-ons transform the visual environment of your flights. This page covers recommended freeware and payware options for both MSFS and X-Plane.

> Links on this page are provided for information only. VFO is not affiliated with any scenery developer.

## MSFS scenery

### Freeware

The most convenient source for free MSFS scenery is [flightsim.to](https://flightsim.to). It hosts thousands of user-made airports and landscape improvements, all free to download.

A good starting point:

- Search for your home airport — there is often a freeware version with improved detail
- **UK2000** and **FlyTampa** offer some free legacy scenery converted for MSFS
- The **Bing Maps** satellite data built into MSFS already provides a good global baseline

### Payware

Commercial MSFS scenery is sold through:

- **Microsoft/Asobo in-game Marketplace** — convenient, installs automatically
- **Orbx** ([orbxdirect.com](https://orbxdirect.com)) — known for landscape region packs and airports
- **SimMarket** ([simmarket.com](https://www.simmarket.com)) — large catalogue across many developers
- Individual developer websites (FlyTampa, Aerosoft, LatinVFR, etc.)

### World updates

Microsoft releases free **World Updates** for MSFS that improve photogrammetry, hand-crafted airports, and POIs for specific regions. These are downloaded free from the in-game Marketplace. Check for any updates you may have missed in the Content Manager.

## X-Plane scenery

### Freeware

- **X-Plane.org** ([x-plane.org](https://www.x-plane.org)) — the main repository for X-Plane add-ons. Search for airports by ICAO code.
- **Global Airports** — X-Plane ships with the Global Airports scenery library, which covers nearly every ICAO airport. Quality is functional but basic.
- **OpenSceneryX** — a freeware library many add-on airports depend on. Install this first.

### Payware

- **Orbx** ([orbxdirect.com](https://orbxdirect.com)) — extensive catalogue for X-Plane, including TrueEarth landscape packs
- **Aerosoft** — airports and aircraft for X-Plane
- **4Simmers** — European airports

### Ortho4XP

**Ortho4XP** is a free tool that generates satellite-imagery based terrain tiles for X-Plane from open-source map data (e.g. ESRI, Bing). It dramatically improves the landscape at the cost of large file sizes and a one-off generation time. It is a community-favourite but requires some technical setup — guides are available on the X-Plane.org forums.

## General tips

- Always check **scenery compatibility** with your current simulator version before purchasing
- Maintain an **add-on manager** (e.g. MSFS Addons Linker for MSFS) to keep your scenery library organised and load times manageable
- For VFO group flights, use a scenery pack for the event destination if you have one — it improves the visual experience considerably
