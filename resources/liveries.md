# Liveries

VFO has a range of community liveries for use in Microsoft Flight Simulator. The liveries feature the VFO corporate colour scheme and branding, making it easy to identify fellow VFO pilots during group flights.

## Where to find them

All VFO liveries are created by community member **MisterO** and published on flightsim.to:

[Browse VFO liveries on flightsim.to](https://flightsim.to/profile/MisterO){: .btn .btn-blue }

## Installing liveries

Liveries from flightsim.to can be installed using the **MSFS Addons Linker** or by copying them directly to your Community folder. Installation instructions are included with each download on the flightsim.to page.
