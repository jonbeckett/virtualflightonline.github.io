# Glossary

Key terms used across VFO, the VFO airline, and flight simulation generally.

| Term | Definition |
| --- | --- |
| **ACARS** | Aircraft Communications Addressing and Reporting System. In the VFO context, the desktop client that tracks your flight and files a PIREP automatically. |
| **AIRAC** | Aeronautical Information Regulation and Control. A 28-day cycle on which navigation data (waypoints, airways, procedures) is updated. Important for keeping FMS databases current. |
| **API key** | A unique secret token that identifies your VFO airline account to the ACARS client. Found on your profile page at airline.virtualflight.online. |
| **ATIS** | Automatic Terminal Information Service. A continuous broadcast of current weather, active runways, and NOTAMs at busy airports. Listen before calling for taxi clearance. |
| **Bid** | Reserving a flight number on the VFO airline system so it counts toward your rank progress. Bids are placed through the airline website. |
| **BKN** | Broken cloud cover (5–7 eighths of sky covered). Counts as a ceiling for VFR purposes. |
| **Callsign** | Your unique identifier used in radio communications and on the live radar. On the VFO airline, your callsign follows the format VFO + your pilot number. |
| **CAT** | Clear Air Turbulence. Turbulence at high altitude in clear conditions, caused by jet stream wind shear. No visible warning. |
| **Ceiling** | The height of the lowest broken or overcast cloud layer. Determines whether VFR flight is possible. |
| **DME** | Distance Measuring Equipment. Ground-based radio beacon that reports slant-range distance to the station. |
| **FBO** | Fixed Base Operator. A service facility at an airport providing fuel, handling, and other services. |
| **FMS / FMC** | Flight Management System / Flight Management Computer. The on-board navigation computer used to programme and fly a route. |
| **FPL** | Flight plan. A filed document stating your route, aircraft, and intentions. |
| **HOTAS** | Hands on Throttle and Stick. A hardware setup combining a joystick and throttle, popular in flight and combat simulation. |
| **ICAO** | International Civil Aviation Organisation. Also used to refer to the four-letter airport codes (e.g. EGLL for London Heathrow). |
| **IFR** | Instrument Flight Rules. Regulatory framework for flight in cloud or low visibility using instruments rather than outside visual references. |
| **ILS** | Instrument Landing System. A ground-based radio navigation system providing lateral (LOC) and vertical (G/S) guidance to a runway. |
| **LNAV** | Lateral Navigation. Automatic lateral guidance along a programmed FMS route. |
| **METAR** | Meteorological Aerodrome Report. A standardised weather observation report for an airport, issued every 30–60 minutes. |
| **NDB** | Non-Directional Beacon. A radio navigation beacon. The aircraft's ADF needle points toward it. |
| **NOTAM** | Notice to Airmen. Official notice about changes to airport facilities, airspace, or hazards. |
| **OFP** | Operational Flight Plan. The full document generated by SimBrief covering route, fuel, weather, and performance. |
| **OVC** | Overcast. Complete cloud cover (8 eighths). Counts as a ceiling. |
| **PIREP** | Pilot Report. A filed report of a completed flight. On the VFO airline, this records the flight in your logbook and awards hours and pay. |
| **Pushback** | Moving an aircraft backwards away from a gate using a tow vehicle (or the BetterPushback plugin in simulation). |
| **QNH** | The barometric pressure setting that makes your altimeter read field elevation when on the ground. Set this from the ATIS or METAR. |
| **RNAV** | Area Navigation. GPS-based navigation that allows flight on any path, not just routes between radio beacons. |
| **SCT** | Scattered cloud cover (3–4 eighths). Does not count as a ceiling. |
| **SID** | Standard Instrument Departure. A published departure procedure from a runway to the en-route structure. |
| **Squawk** | A four-digit code set on the transponder to identify your aircraft to ATC radar. 7700 = emergency, 7600 = radio failure, 7500 = hijack. |
| **STAR** | Standard Terminal Arrival Route. A published arrival procedure bringing aircraft from the en-route structure to the approach. |
| **TAF** | Terminal Aerodrome Forecast. A weather forecast for an airport, typically covering 24–30 hours. |
| **Transponder** | An avionics device that responds to radar interrogation, broadcasting your aircraft's identity and altitude. |
| **UTC / Zulu** | Coordinated Universal Time. The international time standard used in all aviation. VFO event times are always given in UTC. |
| **VFR** | Visual Flight Rules. Flight conducted by visual reference to the ground and sky, in conditions of sufficient visibility and clear of cloud. |
| **VNAV** | Vertical Navigation. Automatic vertical profile guidance along a programmed FMS descent or climb path. |
| **VOR** | VHF Omnidirectional Range. A ground-based radio navigation beacon broadcasting 360 radials. Aircraft navigate to/from a VOR using a VOR receiver or OBS. |
| **Waypoint** | A fixed geographical position used to define a route. Identified by a 5-letter name (e.g. LOGAN, SOSIM). |
