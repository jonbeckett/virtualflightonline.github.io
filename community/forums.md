# Forums and discussion

VFO does not have a separate forum platform. All community discussion happens in the [Discord server](discord.md), using a set of channels that serve the same purpose as traditional forum categories.

## Discussion channels

| Channel | Purpose |
| --- | --- |
| **#general** | General conversation — anything aviation or simulator related |
| **#screenshots** | Share your best shots from flights |
| **#aircraft** | Discussion about add-on aircraft, liveries, and configurations |
| **#scenery** | Scenery add-ons, airports, and landscape improvements |
| **#technical-help** | Questions about MSFS, X-Plane, ACARS, or the Transmitter |
| **#real-world-aviation** | News, videos, and discussion about real-world aviation |
| **#off-topic** | Everything else |

Channel names may change over time — the Discord server is the authoritative source.

## Async communication

Discord is primarily a live-chat tool, but channels also work well for asynchronous conversation. If you post a question and no one is online, replies will appear when other members check in later.

For topics that benefit from longer-form writing — such as a detailed technical question or a flight report — you can use Discord's thread feature. Threads keep extended conversations tidy without cluttering the main channel.

## Getting answers

The community is friendly and experienced. If you have a question about VFO operations, the airline system, or simulator setup, post it in **#technical-help** or **#general**. Include:

- Which simulator you are using
- What you have already tried
- Any error messages or screenshots if relevant

You will usually get a response quickly when members are online, and more slowly overnight or at quiet periods.

## Staying informed

To make sure you do not miss important announcements:

- Enable **notifications** for the **#announcements** channel in Discord (right-click the channel and select Notification Settings)
- Check the **Discord Events** tab in the server for upcoming group flights
- Watch **#group-flights** for last-minute fly-in invitations
