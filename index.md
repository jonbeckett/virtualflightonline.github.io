# Virtual Flight Online

Virtual Flight Online is a community hub for sim pilots who want to fly together, share ideas, and build practical tools around modern flight simulation. This draft site brings together the structure of the original Google Sites pages while the content is being migrated into GitHub Pages.

## What you can find here

- Community links for Discord, Facebook, newsletters, and support
- Draft documentation for the VFO Transmitter ecosystem
- Entry points for the Codex knowledge base and virtual airline activity
- A clearer structure for future guides, operations notes, and reference material
