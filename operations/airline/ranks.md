# Ranks

As you file flights with the airline and accumulate hours, you progress through a series of ranks. Your rank determines which aircraft you can fly, and therefore which scheduled flights and tours are available to you.

## Rank structure

| Rank | Hours required | Aircraft access |
| --- | --- | --- |
| Student Pilot | 0 | Basic trainers (see [Fleet](fleet.md)) |
| Private Pilot | 1 hour | All GA aircraft |
| Class D First Officer | 20 hours | Transport aircraft |
| Class D Captain | 40 hours | Transport aircraft |
| Class C First Officer | 60 hours | Business jets |
| Class C Captain | 80 hours | Business jets |
| Class B First Officer | 100 hours | Commercial airliners |
| Class B Captain | 120 hours | Commercial airliners |
| Class A First Officer | 140 hours | Intercontinental airliners |
| Class A Captain | 160 hours | Intercontinental airliners |

## What your rank affects

- **Aircraft types** — each rank unlocks a new set of aircraft (see the [Fleet](fleet.md) page for the full list)
- **Scheduled flights** — flights tied to aircraft types become available as you qualify for those aircraft
- **Tours** — some tours are restricted to specific rank classes

Not all flights are rank-restricted. Free flights and many tour legs are open to all.
