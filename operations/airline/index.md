# Airline

The VFO virtual airline is a structured flying activity built on **phpVMS**. It lets pilots log flights, earn ranks, follow tours, and build a personal pilot record.

The airline is hosted at [airline.virtualflight.online](https://airline.virtualflight.online).

## Getting started

If you are new to the airline, start with the [Beginners Guide](beginners-guide.md) — it walks you through registration, installing ACARS, and completing your first flight.
